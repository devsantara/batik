## Status

Batik is in early development. **Nothing is published to npm yet**, so there is
no install command to give you. The repository is public so the design work
happens in the open — watch it or open a discussion if you want to follow along.

## What it is

Batik treats design tokens as the interface. Instead of shipping components that
happen to be themeable, it defines the token layer first — color, spacing,
typography, elevation — and builds everything else on top of it, compiled by
[StyleX](https://stylexjs.com) into static CSS with no runtime cost.
